# Standard 02: Chain of Custody Protocol

### 2.1 Chain Continuity Mandate

Every physical and digital touchpoint must be chronologically continuous.

### 2.2 Custody Record Invariants

1. Document SHA-256 must match across all transactions.

2. Previous event hash pointer must form unbroken hash chain.

3. Timestamp must monotonically increase.

### 2.3 Custody Handoff Procedures

- Dual signoff between outgoing and incoming custody officers.
